## Cómo instalar

**Windows:** descomprima el `.zip` y abra `Taxista Furioso.exe`. El `.pck` tiene que quedar en la misma carpeta. Como el juego no está firmado, Windows puede mostrar "Windows protegió su PC": pulse **Más información → Ejecutar de todas formas**.

**Linux:** descomprima con `tar -xzf TaxistaFurioso-Linux.tar.gz` y abra `Taxista Furioso/Taxista Furioso.x86_64`. Si no arranca, dele permiso de ejecución con `chmod +x`.

**Android:** descargue el `.apk` en el celular y ábralo. Android le pedirá permitir la instalación de apps de origen desconocido para el navegador o el administrador de archivos. Es una versión de prueba (firmada en modo depuración), todavía no está en Google Play.

## Controles

Teclado (WASD + J, K, L), control de Xbox, PlayStation o Nintendo, o controles táctiles en el celular. Dentro del juego, **Opciones → Controles** muestra todo.

Este repositorio solo guarda las descargas; el código del juego es privado.
